Quick Start

Start using hue.gl colors in minutes

Using CSS Variables

The simplest way to use hue.gl is with CSS variables:

/* Import the stylesheet */
@import 'hue.gl/dist/css/hue.gl.css';

/* Use any color */
.button {
  background: var(--N2405);  /* Blue, shade 5 */
  color: var(--N0601);       /* Yellow, shade 1 (light) */
}

.card {
  border: 1px solid var(--N1803);  /* Cyan, shade 3 */
}

Using SCSS

Import SCSS variables and maps for more control:

@use 'hue.gl/dist/scss/hue.gl' as hue;

.element {
  // Use color variables
  background: hue.$n240-5;

  // Use the color map
  color: map-get(hue.$colors, 'N0601');
}

Using JavaScript

Import colors programmatically:

import { ColorScheme, getColor } from 'hue.gl';

// Get a specific color
const blue = getColor('N2405');
console.log(blue.hex);  // #3b82f6
console.log(blue.rgb);  // [59, 130, 246]
console.log(blue.lch);  // [55, 70, 240]

// Create a color scheme instance
const scheme = new ColorScheme();
const palette = scheme.getHue('blue');

Color Theory

Understanding perceptual color and the NIJI system

Perceptual Uniformity

Traditional color spaces like RGB and HSL don't account for how humans perceive color. A 10-unit change in one part of the spectrum may look dramatically different than the same change elsewhere.

hue.gl uses the LCH (Lightness, Chroma, Hue) color space, which is designed to be perceptually uniform. This means:

  • Equal changes in values produce equal perceived changes
  • Shades across different hues have consistent visual weight
  • Color relationships are more predictable and harmonious

The NIJI System

NIJI (虹, Japanese for "rainbow") is a systematic approach to color organization:

Universal Compatibility

NIJI colors are designed to work seamlessly across all color systems and spaces, ensuring consistent results in any medium.

24 Hues

The color wheel is divided into 24 hues at 15° intervals, providing comprehensive coverage while maintaining distinct, nameable colors.

9 Shades

Each hue has 9 shades ranging from very light (96L) to very dark (12L), with carefully calculated chroma values.

Systematic Naming

Colors are named with prefix + shade + hue degree, making them programmatically accessible and human-readable.

Gamut Awareness

Colors outside the sRGB gamut are clearly marked, helping designers stay within displayable colors.

Universal Color System Support

One of the key strengths of the NIJI color system is its universal compatibility. Because colors are defined in the perceptually uniform LCH space, they can be accurately converted to any other color model while maintaining their intended appearance:

LCH Color Space

Understanding Lightness, Chroma, and Hue

What is LCH?

LCH stands for Lightness, Chroma, and Hue. It's a cylindrical representation of the CIELAB color space, designed to align with human color perception.

L — Lightness

Ranges from 0 (black) to 100 (white). Represents the perceived brightness of the color.

0 → 100

C — Chroma

Represents color intensity or saturation. Higher values are more vivid, lower values are more muted.

0 → 150+

H — Hue

The color angle on the color wheel, from 0° to 360°. Red is around 0°/360°, yellow at 90°, etc.

0° → 360°

hue.gl LCH Configuration

ParameterValueDescription
l_l_min96Starting lightness (lightest shade)
l_l_step-6Lightness step between shades

Gamut Considerations

Not all LCH colors can be displayed on sRGB screens. Colors outside the sRGB gamut are marked in the palette. When using these colors, they are automatically mapped to the nearest in-gamut color.

Accessibility

Creating accessible color combinations

WCAG Contrast Requirements

The Web Content Accessibility Guidelines (WCAG) define minimum contrast ratios:

  • AA Normal Text: 4.5:1 minimum
  • AA Large Text: 3:1 minimum
  • AAA Normal Text: 7:1 minimum
  • AAA Large Text: 4.5:1 minimum

Recommended Combinations

Tips for Accessible Design

  • Use shade 1-2 backgrounds with shade 8-9 text
  • Use shade 8-9 backgrounds with shade 1-2 text
  • Avoid combining colors that are close in lightness
  • Test with color blindness simulators
  • Don't rely on color alone to convey information

JavaScript API

Programmatic access to the color system

ColorScheme Class

import { ColorScheme } from 'hue.gl';

const scheme = new ColorScheme();

// Get all colors
const colors = scheme.colors;

// Get a specific hue
const blues = scheme.getHue('blue');

// Get a color by name
const color = scheme.getColor('N2405');
console.log(color.hex);   // '#3b82f6'
console.log(color.rgb);   // [59, 130, 246]
console.log(color.lch);   // [55, 70, 240]

Helper Functions

import { getColor, getHex, getRGB, getLCH } from 'hue.gl';

// Get full color object
const color = getColor('N2405');

// Get specific format
const hex = getHex('N2405');   // '#3b82f6'
const rgb = getRGB('N2405');   // [59, 130, 246]
const lch = getLCH('N2405');   // [55, 70, 240]

TypeScript Support

hue.gl includes full TypeScript declarations:

import type { Color, ColorName, HueName } from 'hue.gl';

const colorName: ColorName = 'N2405';

SCSS Functions

Advanced color manipulation with SCSS

Import

@use 'hue.gl/dist/scss/hue.gl' as hue;

Variables

.element {
  background: hue.$n240-5;
  color: hue.$n240-1;
}

Color Map

// Access colors from the map
$my-color: map-get(hue.$colors, 'N2405');

// Loop through all colors
@each $name, $value in hue.$colors {
  .bg-#{$name} {
    background-color: $value;
  }
}

Functions

// Get a color by name
$blue: hue.get-color('N2405');

// Get all shades of a hue
$blues: hue.get-hue(240);

// Generate a tint/shade
$light-blue: hue.tint($blue, 20%);
$dark-blue: hue.shade($blue, 20%);
